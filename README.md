# 🔍 Сапер для iPhone

Классическая игра "Сапер" для iOS, созданная с использованием SwiftUI.

## 📱 Возможности

- **Классический геймплей**: Найди все мины на игровом поле 10x10
- **Интуитивный интерфейс**: Простое управление касаниями
- **Флажки**: Долгое нажатие для установки флажков на подозрительные клетки
- **Таймер**: Отслеживание времени игры
- **Счетчик мин**: Показывает количество оставшихся мин
- **Автоматическое открытие**: Пустые клетки автоматически открывают соседние
- **Цветовая индикация**: Разные цвета для разного количества соседних мин

## 🎮 Как играть

1. **Цель**: Найти все мины на поле, не наступив ни на одну
2. **Касание**: Обычное касание открывает клетку
3. **Флажок**: Долгое нажатие ставит/убирает флажок
4. **Числа**: Показывают количество мин в соседних клетках
5. **Победа**: Откройте все безопасные клетки
6. **Поражение**: Случайное попадание на мину

## 🚀 Запуск приложения

### Требования
- Xcode 15.0 или новее
- iOS 17.0 или новее
- macOS для разработки

### Установка
1. Откройте терминал и перейдите в директорию проекта
2. Откройте проект в Xcode:
   ```bash
   open Minesweeper.xcodeproj
   ```
3. Выберите симулятор iPhone или подключенное устройство
4. Нажмите кнопку Run (▶️) или используйте Cmd+R

### Альтернативный способ
Если у вас нет Xcode, вы можете открыть проект следующим образом:
```bash
xcodebuild -project Minesweeper.xcodeproj -scheme Minesweeper -destination 'platform=iOS Simulator,name=iPhone 15' build
```

## 🎯 Особенности реализации

- **SwiftUI**: Современный декларативный UI фреймворк
- **MVVM**: Архитектура Model-View-ViewModel
- **ObservableObject**: Реактивное обновление интерфейса
- **Timer**: Встроенный таймер для отслеживания времени
- **Gesture Recognition**: Поддержка касаний и долгих нажатий

## 🎨 Интерфейс

- **Заголовок**: Название игры с эмодзи
- **Статистика**: Счетчик мин и таймер
- **Игровое поле**: Сетка 10x10 с интерактивными клетками
- **Статус игры**: Индикация победы/поражения
- **Кнопка новой игры**: Для перезапуска

## 🔧 Настройки игры

В файле `MinesweeperGame.swift` можно изменить:
- `gridSize`: Размер игрового поля (по умолчанию 10)
- `totalMines`: Количество мин (по умолчанию 20)
